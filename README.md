# Skills Tracker

A desktop app for tracking the skills you're learning and how your progress builds over time . Built with Python and SQLite.

## Overview

Skills Tracker lets you log the skills you're working on, update your progress as you improve, and keep a persistent record of your learning journey. All data is saved automatically to a local SQLite database, so your progress is never lost between sessions.

## Features

- Add new skills to track
- Log and update progress over time
- Automatic persistence via SQLite — no manual saving needed
- Update existing entries without losing history

## Tech Stack

- **Python** — core application logic
- **SQLite** — local, persistent data storage

## Getting Started

### Prerequisites
- Python 3.x installed on your machine

### Installation & Run
```bash
# Clone this repo
git clone https://github.com/Mary-Far8/Skills-Tracker.git
cd Skills-Tracker

# Run the app
python "Skills Tracker.py"
```
